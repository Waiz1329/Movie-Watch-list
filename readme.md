# 🎬 Movie Watchlist (CineVault)

A simple CRUD Movie Watchlist web application built using **HTML, CSS, JavaScript, Node.js, and Express.js**.

This project allows users to manage their personal movie collection by adding, viewing, updating, and deleting movies through a REST API with a clean and modern user interface.

---

## 🚀 Features

- 🎥 Add a new movie
- 📋 View all movies
- ✏️ Edit existing movie details
- 🗑️ Delete movies
- 🎨 Modern responsive dark theme UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Fetch API)
- Node.js
- Express.js

## 📌 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/` | Welcome message |
| GET | `/movies` | Get all movies |
| GET | `/movies/:id` | Get a movie by ID |
| POST | `/movies` | Add a new movie |
| PUT | `/movies/:id` | Update a movie |
| DELETE | `/movies/:id` | Delete a movie |

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/movie-watchlist.git
```

### 2. Open the project folder

```bash
cd movie-watchlist
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

The server will run at:

```
http://localhost:3000
```

### 5. Open the frontend

Open **index.html** using Live Server or your browser.
